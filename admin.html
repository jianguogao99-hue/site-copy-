访问数据 / 02

访问总览

按公开 IP 汇总页面访问；同一网络下多人可能共用一个 IP。

本站全部仅汇总当前站点自己 D1 中的记录；域名前带 www 与不带 www 合并显示。

访问次数—打开页面的次数；请求日志连文件请求也算，所以通常更多
不同 IP—所选时间内按 IP 只算一次，共用网络可能多人同 IP
最高访问地区—按 IP 估计位置，并非精确地址
机房 IP—所选时间内的不同 IP 占比
疑似真人—IP 数：有非测试返佣点击和浏览器请求，且未见探测
机器人与扫描—IP 数：命中过可疑路径或已知爬虫标识，仅是线索
未分类—IP 数：证据不足，不强行判定

三类按 IP 数分层，总和等于“不同 IP”；只用仍保留的请求与点击线索。旧请求清理后可能转入“未分类”，不影响访问次数。
